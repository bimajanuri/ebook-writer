# Preset Gaya

| Gaya | Ciri |
|---|---|
| Formal | Baku, resmi, tanpa basa-basi. |
| Academic | Berbasis bukti, hati-hati, istilah terdefinisi, sitasi terjaga. |
| Professional | Langsung, berorientasi tindakan, konkret. |
| Casual | Natural, hangat, percakapan yang wajar. |
| Diplomatic | Taktis tanpa mengaburkan masalah. |
| Educational | Bertahap, jelas, contoh terkontrol. |
| Simple | Kalimat pendek, istilah dijelaskan, mudah dipindai. |
| Confident | Tegas, aktif, tanpa kepastian palsu. |
| Marketing | Berorientasi manfaat, tanpa hype atau bukti palsu. |

Untuk fiksi, kunci juga:

- sudut pandang;
- kala penceritaan;
- jarak narator;
- ritme;
- kepadatan dialog;
- tingkat emosional;
- batas konten.

Jika gaya belum jelas, minta pengguna memilih maksimal tiga opsi yang paling cocok.
